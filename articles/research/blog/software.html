Software

In essence, I try to put all my (highly unpolished and probably inefficient, but working) code online that generated the examples in the papers I write. The complete list can be found here: https://gitlab.com/releases-c-verhoek. For your convenience I'll make a short list here (in the future):

  • Data-driven predictive control for LPV systems
    The code corresponding to the paper ''Data-Driven Predictive Control for Linear Parameter-Varying Systems'' can be found here: https://gitlab.com/releases-c-verhoek/lpv-data-predictive-control.
  • Data-driven interpolation and approximation for LPV systems
    The code corresponding to the paper ''Direct data-driven interpolation and approximation of linear parameter-varying system trajectories'' can be found here: https://gitlab.com/releases-c-verhoek/dd-interp-approx/.
This list is incomplete, as this part is still under construction...
